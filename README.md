# Ahmad Almtere Portfolio

A responsive Arabic portfolio website for Ahmad Almtere, focused on organizational development, process improvement, and workflow automation.

## Run locally
Open `index.html` in any modern browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. In the GitHub repository, open **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. GitHub will provide the published site address.

## Before publishing
Update `hello@ahmadalmtere.com` in `index.html` with the preferred professional email address.
