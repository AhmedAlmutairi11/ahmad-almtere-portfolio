# Ahmad Almtere — professional portfolio

A bilingual, responsive static portfolio hosted on Vercel. Open `index.html` locally to preview. GitHub is only used as the source repository; there is no public GitHub link on the website.

## Site structure

- Hero with `generated-image (1).png` already present in the repository.
- About and services pathways, six service cards with detail dialogs, three general case studies, practical browser-only demonstration tools, recruitment collaboration and contact section.
- Arabic/English toggle; no database or login.

## Service requests

The on-site dynamic form posts to `https://formspree.io/f/xvkgrgjk` using fetch. It shows success only after Formspree returns a successful response. Set and verify the target email `almtereahmad@gmail.com` in the Formspree dashboard and submit a real test request to check delivery and spam folders. Formspree receives and processes the submitted personal information; do not promise zero third-party retention. Do not place confidential client information in a first-contact request.
